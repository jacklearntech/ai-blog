# CLAUDE.md

## Project Overview

AI Blog — a statically-generated personal blog built with Next.js 16 (App Router), Tailwind CSS v4, and MDX. Deploys as pure static HTML via Vercel.

- **Language**: Chinese (zh-CN)
- **Domain**: `ai-blog-vercel.jacklearn.tech`
- **Author**: Jack

## Critical Workflow Rule

**All changes MUST follow this order:**

1. **Update `.ai/` documentation first** — architecture, project map, module docs, or ADRs
2. **Then update code** — implement the actual changes
3. **Verify** — run `npm run build` to confirm static export succeeds

Never modify code without first updating the relevant `.ai/` docs. When adding new features, create new module docs or ADRs as appropriate.

## .ai Documentation Structure

```
.ai/
├── architecture.md          # System architecture, tech stack, data flow
├── project_map.md           # Directory structure, module responsibilities, routes
├── modules/                 # Per-module deep documentation
│   ├── content-pipeline.md  # MDX reading/parsing (src/lib/posts.ts)
│   ├── pages.md             # App Router pages and SSG strategy
│   └── styling.md           # Tailwind CSS v4 + prose typography
└── decisions/               # Architecture Decision Records
    ├── ADR-001-next-mdx-remote.md  # Why next-mdx-remote over @next/mdx
    └── ADR-002-post-build-rss.md   # Why post-build script for RSS
```

| ------------------------ | ----------------------------------------------- |

| Add/remove route         | `project_map.md` routes table                   |

## Key Technical Details

- **Static export**: `output: 'export'` in `next.config.ts` — all pages pre-rendered to HTML
- **MDX compilation**: Uses `next-mdx-remote/rsc` (NOT `@next/mdx`) due to Turbopack compatibility. See ADR-001.
- **Content location**: `content/*.mdx` at project root (outside `src/`)
- **RSS**: Generated by `scripts/generate-rss.ts` post-build. See ADR-002.
- **Styling**: Tailwind CSS v4, CSS-first config in `globals.css`. No `tailwind.config.ts`.
- **Dark mode**: System preference only (`prefers-color-scheme`), no manual toggle.
- **Params**: Next.js 15+ requires `await params` for dynamic routes.
